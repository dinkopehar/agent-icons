# agent-icons

Animated agent icons for pull request footers and review comments.

| Icon | File |
| --- | --- |
| Claude Code | `icons/claudecode-walk.svg` |
| Codex | `icons/codex-hop.svg` |
| Claude | `icons/claude-spin.svg` |
| OpenAI | `icons/openai-spin.svg` |

Link them through jsDelivr, pinned to a tag:

```html
<img src="https://cdn.jsdelivr.net/gh/dinkopehar/agent-icons@v1/icons/claudecode-walk.svg" alt="Claude Code" width="24" height="24">
```

The shapes come from [LobeHub Icons](https://github.com/lobehub/lobe-icons) (MIT). The logos belong to their owners.
